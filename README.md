## Project Purpose

A simple Java user login application with automated unit tests, prepared as the application and testing setup for Part 1 of the DevOps assignment.

## Technologies Used

- Java 17
- Maven
- JUnit 5

## Run the Application

From the project root, compile and run the application:

```bash
mvn compile
java -cp target/classes LoginApp
```

## Run the Tests

From the project root, run:

```bash
mvn test
```
